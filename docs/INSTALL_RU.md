# Установка и удаление

1. Создайте резервную копию исходного CE12.0.2 проекта. Требуется Unity6000.3 LTS / Built-in. Остановите Play, дождитесь компиляции.
2. Импортируйте .unitypackage полностью. При первом импорте менеджер устанавливает мод автоматически; исходники сохраняются в ScpCeLightingBackups.
3. SCP → Mods → Lighting Mod Manager: выберите тени/лампы и AO, нажмите Apply. Компонент фоновой засветки — основа мода.
4. Сохранённые параметры пользователя сохраняются. Для варианта без теней выключите их в игровом меню, если ранее включали. Перезапустите редактор после смены графических пресетов, если он сохраняет старые значения.
5. Uninstall восстанавливает исходный C# побайтно, а значения пресетов — с учётом автоматического форматирования YAML самим Unity. После компиляции можно Remove installer files. Не удаляйте резервные копии/ProjectSettings/ScpCeLightingState.json при установленном моде.

Если файлы вручную изменены или проект другой версии, остановка с конфликтом ожидаема. Сохраните свои правки и используйте совместимую базу; не удаляйте state ради обхода проверки. После прерывания операции доступен Recover.

Не устанавливается в готовую Steam-игру. Пакеты персонажей используют другой менеджер и отдельные резервные копии; свет их не удаляет. Само освещение на такой же вручную изменённой версии повторно не устанавливается.
