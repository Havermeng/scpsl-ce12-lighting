# Install / uninstall

Back up a CE12.0.2 / Unity6000.3 LTS / Built-in source project; stop Play and wait for compilation. Import the entire package. First import auto-installs; use SCP → Mods → Lighting Mod Manager for optional components, Apply and Uninstall. Existing saved shadow/AO preferences take priority. Turn shadows off in the game menu if previously enabled; restart the editor if graphics presets have not refreshed.

Keep ScpCeLightingBackups and ProjectSettings/ScpCeLightingState.json while installed. Uninstall restores C# bytes and original preset values (Unity may normalize YAML line endings); then remove the inactive installer with its button. Preserve manual edits before uninstall: conflicts block writes. Recover handles an interrupted transaction. Do not delete receipts/backups to bypass guards. Not a retail EXE/EXILED plugin; character packages have separate ownership and are not removed.
